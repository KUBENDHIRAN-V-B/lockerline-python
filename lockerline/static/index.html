Definition of done

The wall

Forty-eight doors. Green is free, amber is holding. Click a door to read it; a holding door links to its parcel.

Book a door

The courier gives the parcel size and the flat. The wall picks the lowest free door of that size.

Collect

The resident keys the six-digit code. It opens its door once, inside the free window.

How it runs

The image is built from the Dockerfile you write.

Build it, then run it with the database on a named volume and every setting from the env-file (copy .env.example to .env):

docker build -t lockerline .
docker run -d --name lockerline -p 8080:8080 -v lockerline-data:/data --env-file .env lockerline

Restart the container

This page cannot restart the container itself. Press Before restart, run the two commands in a terminal, wait for the health dot, then press After restart: it compares the holding doors and their parcel ids with the ones saved before.

docker rm -f lockerline
docker run -d --name lockerline -p 8080:8080 -v lockerline-data:/data --env-file .env lockerline
